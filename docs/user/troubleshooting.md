# Customer troubleshooting

> Status: Draft, pending HTS review. Owner: HTS team. Historical frontend baseline: 2026-10-02. Current edition: Unreleased.

## Next does not advance

Read the current step's messages and complete required fields. Check contact formats and text limits. For an existing website or reference, use a complete HTTP/HTTPS address without embedded credentials. Blank optional existing-site addresses do not need to be invented. Use synthetic information when reporting a problem.

## A control is hidden on a phone or at zoom

Scroll within the page and check whether the browser is using an unusual window width. Report the exact viewport, zoom, theme and language with a cropped screenshot. Every navigation and download action should remain accessible; reducing zoom is not the intended permanent fix for a layout defect.

## The page is visible but buttons do not respond

Check your connection and wait for Blazor to reconnect. Reload only after considering that the draft can be lost. If the issue persists, report it with the browser and affected action. Never paste personal answers or credentials into public troubleshooting messages.

## Download did not appear

Confirm that the review is valid and the browser allows the action. Check the browser's downloads list for `briefing-hts.txt`. Open it in a text editor supporting UTF-8. Download success does not mean delivery to HTS.

## My answers disappeared after reloading

This iteration does not persist drafts. Re-enter the answers or use a previously downloaded copy. Theme/language persistence is independent. Ask the HTS team through a known channel if you need assistance; the repository has no configured support mailbox or public status page.
